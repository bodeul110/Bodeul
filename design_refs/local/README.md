# 로컬 디자인 캐시

이 디렉터리는 Git에 올리지 않는 일회성 Figma export와 비교 캐시를 둔다.

## 원칙

- 현재 원본은 Figma `보들 가이드`의 `Page 2(460:2)`다.
- ZIP, PDF, PNG와 contact sheet는 원본이나 요구사항 근거가 아니다.
- export가 필요하면 `figma-export-YYYY-MM-DD/`처럼 날짜가 드러나는 디렉터리를 사용한다.
- 검토가 끝난 산출물은 Figma에서 다시 확인할 수 있으면 삭제한다.
- 프로젝트 문서에는 로컬 파일 경로 대신 Figma node ID와 확인일을 남긴다.

현재 추적 대상은 이 README뿐이다.
