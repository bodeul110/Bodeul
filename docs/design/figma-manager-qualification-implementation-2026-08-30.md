# Figma MVP 매니저 자격 인증 구현 판단

- 작업 목적: Figma MVP의 매니저 자격 인증 화면(`8:3183`)을 기존 Android 서류 제출 흐름에 적용한다.
- 선택한 방식: 기존 저장소 계약을 유지하되 MVP 최소수집 정책에 맞춰 직무 자격 증빙 1종만 화면·업로드·검토 요청의 필수 조건으로 사용한다.
- 검토한 대안: 기존 신분증·범죄경력 원본 카드까지 유지하는 방식을 검토했으나 확정된 최소수집 정책과 충돌해 제외했다.
- 선택 이유: 간호사 면허증 또는 요양보호사 자격증 중 하나만으로 요청할 수 있어야 하며, 신분증·범죄경력·건강 관련 원본은 MVP 앱에서 받지 않는다.
- 호환성: 기존 `healthCertificate` 키는 실제 간호사 면허 파일을 잃지 않기 위한 읽기 별칭으로만 취급한다. #383에서 `nursingLicense` 이관이 완료되면 새 키로 교체한다.
- 리스크: 완료 팝업은 실제 저장 성공 콜백에서만 노출되므로, 이미 검토 대기 상태인 계정에서는 요청 상태를 초기화하지 않는 한 반복 확인할 수 없다.

## 이번 적용 범위

- Android 15, display cutout, 3버튼 탐색 안전 영역을 반영한 상·하단 고정 영역
- 제목, 신뢰 기반 시스템, 개인정보 보호 안내 카드
- 점선 업로드 카드, 개인정보 보호 배지, 고정 인증 요청 버튼
- 간호사 면허증 또는 요양보호사 자격증 1종의 미리보기·다시 선택 동작
- JPEG·PNG·WebP 이미지 1개, 10 MiB 이하 업로드 제한
- Figma에서 내보낸 벡터 경로를 Android VectorDrawable로 변환해 고밀도 기기에서도 선명하게 표시
- 닫기·건너뛰기 터치 영역을 48dp 이상으로 확보하고 제출 중에는 화면 이탈과 중복 제출 차단
- 검토 요청 저장 성공 상태를 저장하고 수명주기 안전한 `DialogFragment`로 완료 팝업(`8:2590`) 표시
- 근거가 확정되지 않은 승인 처리 시간 문구는 표시하지 않음

## 후속 연결 조건

- 검토 대기·반려·승인 상태는 기존 화면 모델의 버튼 활성화 규칙을 유지한다.
- #383의 최소수집·`nursingLicense` 이관이 병합되면 legacy 별칭을 새 문서 키로 교체하고 제출·재제출 경계를 함께 회귀 검증한다.
- 화면은 #385 인증 화면 변경 위에서 관리하며, 선행 PR이 병합될 때 최신 `master`로 재배치한다.
