# Figma MVP 매니저 자격 인증 구현 판단

- 작업 목적: Figma MVP의 매니저 자격 인증 화면(`8:3183`)을 기존 Android 서류 제출 흐름에 적용한다.
- 선택한 방식: 기존 저장소·코디네이터·화면 모델은 유지하고, 레이아웃과 표시 리소스만 Figma 구조로 교체한다.
- 검토한 대안: Figma처럼 단일 업로드 카드만 남기거나 새 인증 전용 화면을 추가하는 방식을 검토했다.
- 선택 이유: 실제 앱은 신분증, 간호사/요양보호사 자격증, 범죄경력회보서를 각각 저장하고 검토 요청하므로 기능을 줄이지 않고 시각 구조만 맞추는 편이 안전하다.
- 리스크: Figma 완료 팝업(`8:2590`)은 검토 요청 성공 상태와 함께 연결해야 하므로 이번 화면 스타일 작업에서는 제외한다.

## 이번 적용 범위

- 안전 영역을 반영한 상단 뒤로·닫기 앱 바
- 제목, 신뢰 기반 시스템, 개인정보 보호 안내 카드
- 점선 업로드 카드, 개인정보 보호 배지, 고정 인증 요청 버튼
- 기존 추가 서류 카드와 미리보기·다시 선택 동작 유지
- Figma에서 내보낸 벡터 경로를 Android VectorDrawable로 변환해 고밀도 기기에서도 선명하게 표시
- 닫기와 다음에 인증하기를 기존 화면 종료 동작에 연결

## 후속 연결 조건

- 검토 요청 성공 시 Figma 완료 팝업(`8:2590`)을 표시하되, 저장 성공 콜백 이후에만 노출한다.
- 검토 대기·반려·승인 상태는 기존 화면 모델의 버튼 활성화 규칙을 유지한다.
- 진행 중인 권한 경계 PR이 병합되면 `ManagerDocumentRegistrationActivity`의 세 개 종료 클릭 연결만 재베이스해 충돌 여부를 확인한다.
