## 사용 원칙

- Figma는 화면 구조와 시각 위계의 원본이며 제품 정책이나 기술 계약의 원본이 아니다.
- frame이 존재해도 prototype 연결, 정책 승인과 실제 구현을 각각 확인한다.
- 다운로드 ZIP, PDF, PNG는 임시 비교 자료로만 사용한다.
- 구현 완료 여부는 [현재 구현 상태](../status/implementation-status.md)를 따른다.
