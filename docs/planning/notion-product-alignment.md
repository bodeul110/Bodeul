# Notion 제품 기준 정합성

기준일: 2026-08-28

## 확인 범위

Notion의 MVP 통합본 v1.1, 화면별 상세 명세 v2.2, 동행 채팅 명세 v1.0, 출시 전 법률 체크리스트 v1.0, `개발 정책 관련 내용`, 보유기간 및 파기정책 v1.0을 현재 저장소 구현과 대조했다. 2026-08-25에는 기획 답변과 2026-08-11 법률 검토 의견서를 다시 확인했다. 비공개 URL, 페이지 ID, 계정 정보, 개인정보와 법률 문서 원본은 이 공개 저장소에 기록하지 않는다.

## 현재 제품 흐름

1. 첫 화면과 권한 안내를 거쳐 환자·보호자 또는 매니저 역할을 선택한다.
2. 매니저는 자격 서류 제출과 승인 단계를 거친다.
3. 환자·보호자는 병원, 일정, 건강·이동 정보를 입력해 동행을 요청한다.
4. 현재 구현과 최신 정책 작업안에서는 관리자가 승인된 매니저 한 명을 배정한다. 상세 명세의 선착순 수락은 충돌 상태다.
5. 매칭 이후 매니저는 동행 가이드를 진행하고 환자·보호자는 진행 상태를 확인한다.
6. 최신 정책 작업안은 보호자·매니저 직접 채팅과 주요 상태 알림을 제안한다. 별도 채팅 명세의 시스템 이벤트 중심 동행방과는 충돌한다.
7. 서비스 종료 후 최종 리포트와 후기·후속 처리를 제공한다.

Figma에는 동행 가이드 1~13 화면이 있으나, 현재 서버 계약은 병원 가이드 데이터의 단계 수를 사용한다. `13단계 고정`은 아직 기술 계약이 아니다.

## MVP 임시 결정 원칙

- 기존 기획 답변과 확정 정책은 그대로 유지한다.
- local/dev/preview의 합성 데이터에만 적용되고 설정으로 되돌릴 수 있는 timeout, 재시도, batch, cache, fixture cleanup 같은 값은 개발팀이 정할 수 있다.
- 임시값은 적용 환경, 선택 이유, production 비활성 상태와 재검토 조건을 Issue 또는 PR에 기록한다.
- 실제 개인정보의 수집·보관·삭제, 권한 확대, 비용 발생, 법정 의무 변경은 임시값 위임 대상이 아니다.
- 위험한 미결 항목은 비활성, dry-run 또는 fail-closed를 기본으로 한다.

## 확정해서 유지할 내용

- 예약·세션·채팅·읽음·위치·리포트·후속 처리의 쓰기 원본은 PostgreSQL이다.
- 환자·보호자·매니저 앱은 Spring Core API를 거친다.
- 관리자 웹은 별도 Next.js 서버를 통해 같은 PostgreSQL을 본다.
- Firebase는 Auth, App Check, FCM, Storage와 결합 Functions에 사용한다.
- 인증 프로필·지원·매니저 서류 심사 메타데이터는 현재 Firestore에 남아 있고, 매니저 서류와 세션 첨부 원본은 Firebase Storage에 둔다.
- Realtime은 권위 있는 데이터 원본이 아니라 PostgreSQL 커밋 알림이다.
- OCR, 진료 녹음, STT, AI 요약은 시안이나 문서가 있어도 현재 완료 기능으로 표시하지 않는다.
- 화면별 상세 명세 안에서 음성·STT를 MVP 제외로 둔 문구와 `CLOVA Speech STT → Codex 재가공 실제 구현` 표기가 충돌한다. 저장소에 실제 녹음·STT·AI 처리 경로와 검증 증거가 생기기 전에는 미구현으로 유지한다.

## 문서 정리 판단

- Notion은 제품 의도와 미결 정책의 기준으로 유지한다.
- Notion의 Firestore 컬렉션명, Functions 처리와 구현 완료 표기는 현재 코드의 기술 사실을 대체하지 않는다.
- Notion 문서의 마지막 편집 시각이 저장소 정합성 점검 이후라면 변경된 항목을 다시 대조한다. 미확정 제품값을 production 정책으로 만들지 않으며, 개발 기술 기본값은 [MVP 임시 정책값 결정 경계](mvp-policy-default-boundary.md)에 따라 기록한다.
- 오래된 로컬 기능설명서 PDF는 초기 범위 스냅샷으로 낮춘다.
- 구현 상태는 [현재 구현 상태](../status/implementation-status.md), 기술 구조는 [목표 인프라 구조](../architecture/target-infrastructure.md)를 따른다.
