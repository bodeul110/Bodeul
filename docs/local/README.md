# 로컬 참조 문서

이 디렉터리는 Git에 올리지 않는 원본성 강한 자료와 일회성 참조 파일을 둔다.

## 현재 상태

- `보들_플랫폼_기능설명서.pdf`는 초기 제품 범위를 확인하는 과거 스냅샷이다.
- 현재 MVP 범위는 Notion 기준 문서와 [Notion 제품 기준 정합성](../planning/notion-product-alignment.md)을 우선한다.
- 현재 화면 구조는 [Figma 현행 화면 지도](../design/figma-current-screen-map.md)를 따른다.

## 원칙

- 바이너리 원본은 커밋하지 않는다.
- 로컬 파일은 현재 요구사항이나 구현 완료의 단독 근거로 사용하지 않는다.
- 팀 공유가 필요한 내용은 비밀값·개인정보를 제거한 Markdown 기준 문서로 옮긴다.
- 최신 기준과 충돌하면 [기획·디자인·구현 기준](../planning/source-of-truth.md)의 책임 구분을 따른다.
