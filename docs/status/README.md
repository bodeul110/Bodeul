## 갱신 원칙

- 코드 병합, 배포, 실제 연동 검증과 남은 작업을 구분해 요약한다. 미실행을 완료로 쓰지 않는다.
- 장문의 점검 상세는 `../reports/`로 분리하고 여기에는 링크만 남긴다.
- 과거 섹션의 당시 기준 문구가 최신 상태와 충돌하면 문서 상단 최신 요약을 우선한다.
